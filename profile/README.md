## 事業内容

- **受託開発・業務委託** — AI実装、Web／業務システムを設計から実装・運用まで一貫して担当
- **AIX顧問** — 営業・顧客管理の仕組み化とAI活用を、定例ミーティング＋チャット相談で伴走
- **セミナー・研修** — 経営者・現場向けのAI活用セミナー、ハンズオン研修
- **マイクロSaaS** — 自社サービスの開発・運用

公開事例: [おかげ塾 運営基盤](https://nexa-eng.com/services/okage) — スクール・教室向けに、イベント申込・決済・会員管理・学習をひとつに集約。日々の運営操作はAIがMCP経由で実行します。

## 代表について

大手電機メーカーで製造業×ソフトウェアに約15年。北米EVメーカーとの協業工場（米ネバダ）に約5年駐在し、工場の自働化・データ基盤に従事。
「和魂洋才」— 日本のものづくり現場の工夫への敬意と、世界最先端工場の自働化・AI技術を掛け合わせて、地域の経営課題を最短で解決します。
